# Contributing

Bug reports and pull requests are welcome.

1. Fork and clone, then `pip install -e ".[dev]"`.
2. Make your change with a test, and run `python -m pytest`.
3. If you change behaviour, update the README and CHANGELOG.
4. Open a pull request describing the problem and the fix.

Please don't paste real credentials or personal data into issues, tests or examples. Use made-up values.
